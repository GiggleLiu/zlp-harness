# Agent Notes

Your persistent memory for things that are not recoverable from messages, summaries, or the codebase.

What belongs here:

- Durable facts about the project, team roster, and operator preferences.
- Reliable-source policies for external update searches.
- Open hypotheses to test in a later session.
- Multi-session plans that do not fit in a TODO line.
- Friction with the cryochamber or mailbox protocol.

What does not belong here:

- A chronological journal of each session. The hibernate summary and outbox messages already cover that.
- Waiting-for-reply markers. Inbox and outbox files track message state.
- Concrete future wake times. Use `cryo-agent todo add --at <ISO8601>`.

Trim stale notes. Old memory costs tokens every wake.
